# 简体中文界面

此目录为个人分支的中文显示层，默认使用简体中文。词库按页面语境人工编写，不依赖在线翻译服务。

## 覆盖范围

- 管理员注册、登录、密码重设，菜单、页脚、帮助和使用提示。
- 资产组合、持仓编辑、个人设置、图表、资讯订阅、工具、质押与挖矿、资源链接。
- 管理设置、资产与交易市场向导、插件配置、备份、系统监控。
- 按钮、选项、工具提示、校验与确认弹窗，以及图表的文字标签。

币种和股票代码、资产与交易平台名称、合约地址、网址、接口参数、用户填写的数据、代码示例和原始运行日志保留原文。外部新闻正文及第三方实时数据不做自动翻译。新版官方界面中尚未收录的文案显示原文，避免猜译。

## 实现与数据保护

`i18n.js` 在公共页面头部加载，使用本地词库翻译可见文字，并观察后续插入的页面内容。原版 PHP 模板、配置键与计算逻辑保留。少量模板中的动态数据使用 `translate="no"` 标记。

输入框、密码框、笔记和隐藏字段的值不变；选择框保留原始 `value`。提交按钮使用单独的中文显示标签，原节点、监听器、名称和提交值不变。图表只翻译文字属性，不改数值、时间戳、回调或数据来源。原版依赖英文显示文字的“展开/收起”等判断已改为读取原始文案。

动态规则必须匹配完整句子。捕获组默认原样保留，只有明确属于界面词的组才允许通过 `translateGroups` 指定递归翻译；资产名称等用户数据不可加入此列表。

## 维护词库

源文件位于 `zh-CN/*.json`：`common` 为公共术语，其他文件分别对应页面区域。需要更新时修改源 JSON，再在项目根目录执行（Node.js 22 或更新版本，无需安装依赖）：

```powershell
node app-lib/i18n/build.mjs
node app-lib/i18n/build.mjs --check
node --check app-lib/i18n/i18n.js
node app-lib/i18n/tests/test.mjs
```

浏览器回归测试使用独立临时 Chrome 配置和本机测试页面，不访问应用账户或第三方网络。Windows 自动查找 Chrome；也可通过 `CHROME_PATH` 指定浏览器路径。

词库构建拒绝重复键的冲突译文及未锚定的动态规则。公共文案应统一放在 `common.json`。修改后刷新页面即可生效，脚本和样式链接会随文件更新时间更新缓存版本。

同步 `upstream/main` 后，应检查新增加或更改的文案、公共头部加载位置、模板数据保护标记和 `functions.js` 中的显示文字判断，并重新执行测试。保留官方版权、许可与第三方署名。

调试时可在浏览器控制台调用 `OCT_I18N.missing()` 查看未匹配文字（其中也可能包含无需翻译的数据）。临时查看原版英文可运行 `localStorage.setItem('oct_interface_language', 'en'); location.reload()`；恢复中文运行 `localStorage.removeItem('oct_interface_language'); location.reload()`。这只影响当前浏览器的界面语言。
